# 本地工作台 V1 接口约定

根目录：当前项目下的 `职业发展工作台`。Python 3.12 标准库 HTTP 服务，仅监听 127.0.0.1，默认端口 8026；无第三方运行依赖。静态前端在 app，固定内容在 catalog，用户记录在 data，自动历史备份在 backups。

## 所有权
- 主 Agent：server.py、launch.py、启动脚本、集成、测试和交付记录。
- catalog Agent：catalog/*.json、项目卡生成脚本、docs/项目卡、docs/十年职业路线.md、docs/项目总索引.md。
- frontend Agent：app/index.html、app/app.js、app/style.css。
- validation Agent：tests/test_server.py（后端实现后）、独立审查；不改生产文件。

## GET /api/bootstrap
返回 {catalog:{profile,projects,sources,roadmap,capabilities,opportunities},state,derived,token,today}。
catalog由 catalog/catalog.json 提供；state初始来自 catalog/seed.json。
state = {schemaVersion:1,revision:整数,projectStates:{'01':{status:'idea'|'active'|'validated'|'paused'|'archived',favorite:布尔,notes:文本,updatedAt:文本}},evidence:[],facts:[],decisions:[],reviews:[],history:[]}。
所有可变记录有 id、createdAt、updatedAt。
evidence字段：title,category,contribution,source,boundary,status('documented'|'self_reported'|'pending'|'demo'),date。
facts字段：subject,field,scope,value,unit,source,sourceDate,validUntil,status('pending'|'confirmed'|'retired'),reviewer,confirmedAt,notes。除id以外全是文本。confirmed必须填source、reviewer、confirmedAt、validUntil；日期 YYYY-MM-DD。有效截止日期包含当天。
decisions字段：title,kind('就业'|'读研'|'创业'|'其他'),assumptions,evidence,nextStep,exitCondition,reviewDate,status('open'|'closed'),outcome。
reviews字段：projectId,baseline,result,feedback,nextStep,date。实测记录全部为文本。
derived = {facts:[{...原fact,flags:字符串数组,ready:布尔}],conflicts:[{key,subject,field,scope,ids:数组,values:数组}],stats:{readyFacts,pendingFacts,conflictGroups,expiredFacts}}。相同subject/field/scope的未退役且未过期记录值或单位不一致则冲突；单位不同不能合并为相同数值；不自动判断谁对。待核实记录也参与冲突。缺有效期作为待核实，过期记录不影响当前冲突但不能发布。

## 写入
JSON请求头 Content-Type:application/json, X-App-Token: bootstrap.token。客户端只向当前origin请求。
- POST /api/save {expectedRevision,collection:'evidence'|'facts'|'decisions'|'reviews',record:{...}} 新增/更新；返回 {state,derived}。
- POST /api/delete {expectedRevision,collection,id} 删除记录（操作前自动备份）；返回 {state,derived}。
- POST /api/project {expectedRevision,id,patch:{status,favorite,notes}} 保存项目进度；返回 {state,derived}。
- POST /api/import/preview {backup:导出对象} 校验不写入，返回 {counts:{facts,evidence,decisions,reviews,projectStates},message}。
- POST /api/import {expectedRevision,backup:导出对象} 替换记录前自动备份；返回 {state,derived}。
失败 {error:中文错误}；版本冲突409，校验400，禁止403，超大413。失败不能关闭编辑表单/丢失输入。状态过期时提示刷新，不自动覆盖。

## 导出
- GET /api/export?format=json 返回 {app:'career-workbench',schemaVersion:1,exportedAt,state}；备份不含密钥，无在线服务。
- GET /api/export?format=markdown&kind=facts|evidence|decisions|all，或format=csv&kind=facts|evidence|decisions。
- GET /api/facts/publication 返回当前可用的已确认事实Markdown；没有可用事实时返回400而不是空白已审核文案。
- GET /api/project-card?id=01 返回项目卡Markdown及Codex启动提示词。
- GET /docs/<相对路径> 只读文档；GET /api/health 返回 {app:'career-workbench',version:'1.0.0'}。

## catalog约定
profile:{name,positioning,baselineDate,graduation,weeklyHours,principles:[],unknowns:[]}。
project字段：id(01..40),name,category(A..H),categoryName,readiness('now'|'conditional'|'blueprint'|'extend'),horizons:[1,2,5,10],audience,problem,alternatives,personalFit,trigger,inputs:[],outputs:[],nonGoals:[],acceptance:[],continueWhen,stopWhen,firstVersion,sourceIds:[],prompt。项目卡明确这是候选蓝图，不等于软件已开发。
sources:[{id,title,url或path,date,kind,note}]。
roadmap:[{horizon:1,year:2027,title,best,baseline,stress,response,projectIds:[]}（另2/5/10）]。
capabilities:[{name,focus,proof,projectIds:[]}]。
opportunities:[{title,evidence,inference,signals:[],risk,sourceIds:[]}]。

前端要求：中文；温暖纸白+深绿+铜色，编辑手册风格。导航概览/十年路线/40项目库/成果证据/事实中心/决策复盘/备份。库支持搜索分类阶段可用性与收藏筛选，详情抽屉显示完整卡片、复制提示词/下载卡片/进度备注。成果与事实CRUD、来源路径复制、日期提醒。备份预览导入需页面确认，有自动备份提示。键盘可用，有错误与成功反馈，窄屏不横向溢出。无CDN/外部字体/网络请求。任何用户文本转义再显示，不用不受控HTML。
