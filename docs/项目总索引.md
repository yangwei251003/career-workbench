# 40个项目总索引

这40项是经过范围收敛的候选蓝图，不是40个已开发软件。首期只推进13号课程与宣传事实中心，01号成果证据库承担轻量记录。是否启动其余项目，由真实问题、输入条件和反馈决定。

资料基线：2026-10-24。每周投入9—15小时；保留学业、工作、英语、运动与休息，不设逐月满负荷开发表。

准备度中的“可开始”只表示可以用当前资料做小验证，不表示应该立即同时开发；1/2/5/10年是复盘节点，不是交付承诺。

## 使用顺序

1. 先读项目卡的启动条件、现有替代方案和停止条件。
2. 用访谈、表格、现成工具或模拟验证最小问题，再决定是否写应用。
3. 同时只保留一个需要开发的主项目；记录工作尽量少而有用。
4. 完成后保存使用前基线、实际结果和反馈；没有真实数据就明确未验证。
5. 新岗位、新客户或新资源出现时重新选项目，不为了凑齐清单继续。

## 维护与恢复

固定蓝图和来源保存在catalog；实际使用记录属于data，由工作台另行保存。运行catalog/build_catalog_docs.py只重建固定目录、初始种子和文档，不读取或覆盖data中的个人记录。

长期资产是可导出的数据、来源、规则、源码与经验；停止使用的应用可以归档，不必永久维护40套依赖。
