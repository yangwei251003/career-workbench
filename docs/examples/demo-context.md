# 公开版演示数据与使用范围

此版本以虚构用户、合成活动、模拟访谈与冲突课程记录展示工作台功能；不含原作者或其他使用者的私人档案、雇主内部资料、证书、账户、财产数据和本机路径。

- 96 与 112 学时是刻意设置的同一事项冲突，均为待核实；不能把其中一条当成真实机构课程。
- 2028 毕业、9—15 小时及十年路线是说明使用方法的演示情境，请按自己的情况调整。
- 40 张卡全部是候选蓝图。工作台本身的七视图与记录功能已实现，不能据此称 40 个独立软件已完成。
- 外部政策与岗位链接保留研究记录年份，使用时须核实当前适用规则。
- 个人运行记录保存在 data，自动备份在 backups。它们不属于公共源码，不应提交至 GitHub。
